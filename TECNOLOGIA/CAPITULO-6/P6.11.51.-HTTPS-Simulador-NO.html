CRIPTOGRAFÍA DEL PROYECTO

Este simulador utiliza una combinación de criptografía asimétrica para el intercambio de llaves y simétrica para los datos.

Tipo Clave Valor Uso
Pública (Asimétrica) 0x5A Servidor El cliente la usa para cifrar la clave AES.
Privada (Asimétrica) 0xA5 Servidor El servidor la usa para descifrar la clave AES.
Sesión (Simétrica) 0x3C Compartida Cifrado rápido de todos los datos (Pregunta/Respuesta).

EXPLICACIÓN DEL CÓDIGO

El código implementa la función cifrarXOR() que transforma el texto en una cadena Hexadecimal:

String cifrarXOR(String texto, byte clave) {
  String resultado = "";
  for (int i = 0; i < texto.length(); i++) {
    char c = texto.charAt(i) ^ clave; // Operación XOR
    resultado += String(c, HEX);      // Conversión a Hexadecimal
  }
  return resultado;
}
