FUNCIONAMIENTO QUE SE PRETENDE

Este sistema simula una transmisión digital completa, discriminando entre datos ASCII y valores numéricos puros, mientras genera una señal de pulso real para ser visualizada en un osciloscopio.

1. Diferenciación de Datos

  • Modo ASCII: Si escribes "H", se transmite su código binario 01001000.
  • Modo Numérico: Si escribes solo un número (ej: "5"), se transmite su valor binario 00000101 (el número 5 real).

EXPLICACIÓN DEL CÓDIGO (Lógica Osciloscopio)

for (int i = 0; i < binario.length(); i++) {
    if (binario.charAt(i) == '0') {
      digitalWrite(OSC_PIN, LOW); // 0 Voltios
      lcdReceptor.write((byte)0);   // Onda baja en LCD
    } else {
      digitalWrite(OSC_PIN, HIGH);// 5 Voltios
      lcdReceptor.write((byte)1);   // Onda alta en LCD
    }
    delay(15); // Duración de cada bit
}

AJUSTES EN EL OSCILOSCOPIO

Para ver la señal de 8 bits correctamente en Tinkercad o la realidad:

  • Time/Div: 50ms para ver la ráfaga completa.
  • Trigger: Flanco de subida para estabilizar.
