Biestable SR — NAND con Transistores NPN

4 transistores NPN visibles · realimentación cruzada · 1 bit de memoria

📋 Instrucciones: Pulsa SET para guardar un 1 y RESET para guardar un 0. Las curvas naranjas y azules muestran la realimentación cruzada que mantiene el valor guardado aunque sueltes el pulsador.
▸ Biestable SR — transistores NPN con realimentación cruzada
⚡ Control
📊 Estado actual
Bit guardado Q0
Q̄ (complementario)1
T1 — puerta 1 sup.OFF
T2 — puerta 1 inf.OFF
T3 — puerta 2 sup.ON
T4 — puerta 2 inf.ON
Q = 0 — RESET
T3 y T4 conducen. La realimentación mantiene este estado sin señal externa.
💡 Leyenda
Señal de base (SET / RST)
Corriente activa (TRT ON)
Circuito abierto (TRT OFF)
Realim. Q̄ → base T3, T4
Realim. Q → base T1, T2
Alimentación Vcc +5V
Puerta 1 = T1 + T2 en serie → salida Q̄
Puerta 2 = T3 + T4 en serie → salida Q
Q̄ (naranja) realimenta bases T3, T4
Q (azul) realimenta bases T1, T2
