FUNCIONAMIENTO QUE SE PRETENDE

Este proyecto simula un sistema de comunicación digital básico dividido en tres etapas:

  1. LCD 1 (Emisor - Derecha): Punto de origen. Muestra la frase introducida por el usuario de forma fija.
  2. LCD 2 (Canal - Centro): Simula el medio físico. Las letras se desplazan de derecha a izquierda sincronizadas con su código binario (8 bits).
  3. LCD 3 (Receptor - Izquierda): Punto de destino. Las letras aparecen una a una y se van acumulando hasta reconstruir el mensaje original.

CÓDIGO FUENTE (Arduino)

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

//--- CONFIGURACIÓN DE HARDWARE ---
#define DIR_LCD_EMISOR   0x27 // LCD 1 (Derecha)
#define DIR_LCD_CANAL    0x26 // LCD 2 (Centro)
#define DIR_LCD_RECEPTOR 0x25 // LCD 3 (Izquierda)

LiquidCrystal_I2C lcdEmisor(DIR_LCD_EMISOR, 16, 2);
LiquidCrystal_I2C lcdCanal(DIR_LCD_CANAL, 16, 2);
LiquidCrystal_I2C lcdReceptor(DIR_LCD_RECEPTOR, 16, 2);

String fraseCompleta = "";
String fraseReconstruida = "";
bool transmitiendo = false;
int indiceCaracter = 0;

void setup() {
  Serial.begin(9600);
  lcdEmisor.init(); lcdCanal.init(); lcdReceptor.init();
  lcdEmisor.backlight(); lcdCanal.backlight(); lcdReceptor.backlight();
  mostrarMensajesIniciales();
}

void loop() {
  if (Serial.available() > 0) {
    String entrada = Serial.readStringUntil('\n');
    entrada.trim();

    if (entrada.equalsIgnoreCase("Enviar")) {
      if (fraseCompleta.length() > 0 && !transmitiendo) iniciarTransmision();
    } else if (entrada.equalsIgnoreCase("Borrar")) {
      borrarTodo();
    } else {
      fraseCompleta = entrada;
      lcdEmisor.clear();
      lcdEmisor.print(fraseCompleta);
    }
  }

  if (transmitiendo) {
    if (indiceCaracter < fraseCompleta.length()) {
      transmitirSiguienteCaracter();
      indiceCaracter++;
    } else {
      finalizarTransmision();
    }
  }
}

void transmitirSiguienteCaracter() {
  char c = fraseCompleta.charAt(indiceCaracter);
  String binario = charABinario(c);

  lcdCanal.clear();
  lcdCanal.setCursor(16, 0); lcdCanal.print(c);
  lcdCanal.setCursor(16, 1); lcdCanal.print(binario);

  for (int i = 0; i < 24; i++) {
    lcdCanal.scrollDisplayLeft();
    delay(100);
  }

  fraseReconstruida += c;
  lcdReceptor.clear();
  lcdReceptor.print(fraseReconstruida);
}

String charABinario(char c) {
  String resultado = "";
  for (int i = 7; i >= 0; i--) {
    resultado += ((c >> i) & 1) ? "1" : "0";
  }
  return resultado;
}

DESCRIPCIÓN DEL LCD I2C

Un LCD I2C utiliza un expansor de pines PCF8574 que permite controlar la pantalla usando solo 2 cables de datos:

  • SDA (Serial Data): Envía los datos.
  • SCL (Serial Clock): Sincroniza la velocidad de envío.

Gracias al direccionamiento, podemos conectar hasta 127 dispositivos al mismo par de cables, siempre que cada uno tenga una dirección (ID) distinta.
